# HermesStack

Portable AI workstation for low-cost AI development.

## Components

* FreeLLMAPI
* Hermes Agent
* Hermes WebUI
* MCP Servers
* Local Models

## Supported Platforms

* Ubuntu
* Termux
* Windows
* ARM64 devices

## Quick Start

```bash
git clone <repo>
cd HermesStack
./scripts/install.sh
./scripts/start.sh
```

## Goals

* Run AI agents on low-cost hardware
* Provide OpenAI-compatible endpoints
* Support MCP tools
* Work on mobile devices
* Remain fully open source
